# 지원agent 화면 기획서

## 1. 화면 목적
지원agent는 가이드라인과 RD 원본파일을 업로드해 `시스템반영_RD.xlsx`를 생성하고, 변경이력과 파일 메타정보를 함께 관리하는 변환형 업무 화면이다.  
1차 목표는 대시보드보다 먼저 `업로드 → 변환 → 다운로드 → 이력 저장` 흐름을 안정적으로 완성하는 것이다.

## 2. 화면 대상
- 언더라이팅 지원 담당자
- RD 변환 및 검토 담당자
- 산출물 관리 담당자

## 3. 핵심 사용자 흐름
1. 사용자가 링크로 접속한다.
2. 가이드라인 파일과 RD 원본파일을 업로드한다.
3. 업로드 메타정보가 저장된다.
4. `변환하기`를 클릭한다.
5. 시스템이 가이드라인을 분석한다.
6. `상품코드+보험코드` 기준으로 RD를 변환한다.
7. `시스템반영_RD.xlsx`와 변경이력 시트를 생성한다.
8. 사용자가 결과 파일을 다운로드한다.

## 5. 데이터 정책
- 업로드 데이터는 파일 메타정보와 함께 저장한다.
- 변환 결과는 파일 단위와 행 단위 이력을 함께 남긴다.
- 상품은 `상품코드+보험코드` 기준으로 자동 생성한다.
- 상태 변경 시 변경이력을 남긴다.
- 산출물은 버전별로 누적 관리한다.

## 6. 변환 규칙
- 변환 최소 단위는 `상품코드+보험코드 1건`
- 일반/건강 단일건과 간편 단일건이 같으면 자동 반영
- 다르면 검토 대상으로 분리
- 룰형 값은 자동수정보다 검토 플래그 우선
- 가입금액단위는 가이드라인에 명시된 경우만 반영
- 매핑 실패 건은 전체 실패가 아니라 개별 보류 처리
## 7. 상태 정의
- 미착수: 아직 작업 전
- 진행중: 담당자 작업 중
- 보류: 예외 확인 필요
- 완료: 반영 완료

## 8. 화면 스타일 가이드
- 상단은 진한 네이비 계열 히어로
- 본문은 밝은 그레이 배경
- 정보는 카드형 패턴으로 구분
- 상태는 색상 칩으로 표현
- 다운로드와 변환은 시선이 잘 가는 버튼으로 배치

## 9. 1차 MVP 범위
- 파일 업로드
- 메타정보 저장
- 행 단위 변환
- `시스템반영_RD.xlsx` 생성
- 변경이력 시트 생성
- 다운로드 제공
