# 신계약 기준 반영 협업 Agent Pack 인수인계 문서

## 목적

이 문서는 다른 로컬 Codex 환경에서 기존 대화 맥락과 산출물을 빠르게 이어받기 위한 인수인계 자료다.
대화 원문 전체를 옮기는 대신, 결정 사항, 산출물, 수정 이력, 다음 작업 지시문을 요약한다.

## 작업 맥락

사용자는 3개 부서가 협업하는 신계약 기준 반영 업무를 설명했다.

- 신계약 기획: 상품출시 인수기준, 전략 인수기준 수립
- 신계약지원: 시스템 변경 항목 도출, RD 정리, 기계약합산코드 확인, 전산심사 수정/테스트
- 신계약심사: 심사 기준 반영, 전산 메시지 영향 검토, 현장/심사자 공지

중요 전제:

- 신계약 기획에서 가이드라인 작업이 완료되면 신계약지원과 신계약심사는 병렬로 진행된다.
- 단기 적용 대상은 3개 Agent로 제한한다.
- Agent는 최종 판단자가 아니라 초안 작성 보조자다.
- 사람의 검토, 수정, 승인, 최종 반영은 반드시 유지한다.

## 단기 적용 Agent

| 부서 | Agent | 역할 |
|---|---|---|
| 신계약 기획 | 기획 Agent | 기준 변경 구조화 + 유사 특약 비교 |
| 신계약지원 | 지원 Agent | 시스템 영향도 분석 + RD 반영 체크리스트 |
| 신계약심사 | 심사 Agent | 현장 공지/FAQ 초안 생성 |

## 핵심 메시지

한 가지 기준 변경을 3개 부서가 해석 오류 없이 일관되게 반영하도록, 에이전트가 초안과 체크리스트를 만들고 사람은 검토, 수정, 최종 반영을 수행한다.

## 주요 결정 사항

| 항목 | 결정 |
|---|---|
| 자동화 범위 | 초안 작성, 비교, 영향도 분석, 체크리스트 생성, FAQ 초안 |
| 제외 범위 | 인수기준 최종 결정 자동화, 심사 판단 자동화, RD 직접 입력, 시스템 자동 승인, 공지 자동 발송 |
| 사람 개입 | 모든 Agent 산출물은 담당자가 검토/수정/승인 후 반영 |
| 비용 가정 | 월 10회 사용, 17열 x 600행 엑셀 1개 시트 기준 |
| 비용 추정 | 저비용 모델 기준 월 $1~$3, 재실행/검증 포함 초기 파일럿 월 $5 이하 |
| 보안 관점 | 내부망 사용으로 일부 완화 가능하나, 회사 보안 방향성과 연계 필요 |

## 대시보드 수정 이력

1. 처음에는 MD 기획서를 작성했다.
2. 이후 발표용 대시보드 HTML로 변환했다.
3. 예상 질문 영역은 처음에는 탭 구조였으나, 이미지 제출을 위해 모든 답변이 보이도록 정적 카드형 Q&A로 변경했다.
4. AS-IS 프로세스가 기획 중심으로만 보인다는 피드백이 있어, 신계약지원/신계약심사 병렬 프로세스까지 포함하는 3개 레인 구조로 수정했다.
5. 전체 스크롤 캡처 PNG를 생성했다.

## 현재 대시보드 구성

- 상단: 핵심 메시지, 단기 적용 범위, 비용 요약
- 중단: 3개 부서 Agent 카드
- 프로세스: AS-IS 위, TO-BE 아래
- AS-IS: 신계약 기획, 신계약지원, 신계약심사 3개 레인
- TO-BE: 기획 Agent, 지원 Agent, 심사 Agent와 사람 검토/반영 흐름
- 하단: 예상 질문 및 답변 키워드 정적 카드
- 마무리: 완료 정의, 한 줄 결론
