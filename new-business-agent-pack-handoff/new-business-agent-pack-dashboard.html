Static Q&A

약한 가정

초안 목적
기준 변경 구조화가 정확한가? 최종 판단이 아니라 초안 작성 목적. 사람의 수정과 최종 반영을 전제로 운영.
유사 특약 비교를 그대로 믿어도 되는가? 비교 결과는 참고 후보. 복사·반영 여부는 기획 담당자가 승인.
자동화 범위가 넓어지는가? 자동 판단, 직접 입력, 자동 승인 제외 범위를 명시.

테스트/데이터

샘플 검증
테스트 데이터 가이드라인 샘플, 보종코드, RD 양식, 기존 공지문 샘플 활용.
측정 방식 원천 데이터와 초안을 비교. 누락, 오분류, 수정 필요 문장 비율, 담당자 승인 가능 여부 확인.
테스트 목표 완벽한 자동 반영이 아니라, 사람이 검토 가능한 초안 품질 확보.
