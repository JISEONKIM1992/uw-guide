# 신계약지원 Agent 운영 규칙

## 기본 원칙
- `xlsx/csv` 우선으로 처리한다.
- 특약별 판단은 그룹값이 아니라 개별 item을 기준으로 한다.
- 일반/간편 단일건을 최우선 비교값으로 사용한다.
- 인별합산은 참고값으로만 사용한다.

## 질문 처리 규칙
- 질문이 들어오면 현재 로드된 모든 특약 item에서 가장 잘 맞는 항목을 찾는다.
- 질문에 특약명이 있으면 그 특약을 우선한다.
- 보험코드가 있으면 보험코드를 우선한다.
- 답변은 `comparisonSummary`를 우선 근거로 만든다.

## 파일 처리 규칙
- 업로드 파일 메타정보는 반드시 저장한다.
- 변환 결과는 다운로드와 저장을 분리한다.
- 저장 전 결과는 `pendingProducts`로 유지한다.
- 업로드 삭제 시 관련 요약도 같이 초기화한다.

## OpenAI 호출 규칙
- API 키는 로컬 프록시에서만 읽는다.
- 프런트는 직접 OpenAI 키를 알지 못한다.
- payload에는 질문, 선택 특약, 요약, 참고값만 넣는다.
